# Klubbsalg

Salgsapp for klubbeffekter på stand. Salg registreres på telefonen og synkes til et Google Sheet.

- App: https://lerstein.github.io/klubbsalg/
- Backend: `backend/Code.gs` (kopi av Apps Script-prosjektet «Klubbsalg»). Oppsett står øverst i filen.
- Arbeidsregler for endringer: se `CLAUDE.md`.
